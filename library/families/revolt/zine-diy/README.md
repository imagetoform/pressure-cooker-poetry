# Zine / DIY

1930s science-fiction fanzines, then punk from the 1970s: a photocopier, a stapler and something to say. Publishing without permission.

| Kit part | Value |
|---|---|
| Branch | Revolt & noise |
| Emotions (dartboard tags) | interest, annoyance, acceptance |
| Layout grammar | xerox |
| Motion | sty-jitter |
| Button skin | `body[data-sty="zine-diy"]` in site/src/extra.css |
| Colors | #171717 #f0ece3 #fa3a70 |
| Texture | toner |

## Cutouts

Put this movement's cutouts (transparent PNG or SVG) in `cutouts/`. Tag each one in the lab tagger (`?lab=1#/lab`) and paste the entries into the cutout manifest.
