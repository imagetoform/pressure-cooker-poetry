# Minimalism

1960s on. Less, then less again: one line, one mark, a lot of air.

| Kit part | Value |
|---|---|
| Branch | Order & reduction |
| Emotions (dartboard tags) | serenity, acceptance, pensiveness |
| Layout grammar | whisper |
| Motion | sty-fade |
| Button skin | `body[data-sty="minimalism"]` in site/src/extra.css |
| Colors | #111111 #d4251c |
| Texture | none |
