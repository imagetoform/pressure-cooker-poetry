# Afrofuturism

Sun Ra's Arkestra from the 1950s, Octavia Butler, Parliament-Funkadelic; named by Mark Dery in 1993. Black futures imagined by the people the official future left out. A way of seeing more than a single style.

| Kit part | Value |

| Branch | Future & machine |
| Emotions (dartboard tags) | vigilance, awe, admiration |
| Layout grammar | reliquary |
| Motion | sty-rise |

| Colors | #241345 #e99d22 #31c6b4 |
| Texture | dots |
