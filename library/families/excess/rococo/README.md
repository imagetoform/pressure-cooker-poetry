# Rococo

c. 1720s–1770s France. Shell-and-scroll ornament (rocaille), pastels and gold leaf, Boucher's and Fragonard's pleasure gardens: luxury for a class headed for 1789. Played here as satire of fake abundance.

## Where the public-domain material is

18th-century ornament engravings (Meissonier, Cuvilliés, Lajoue, Pillement) and prints after Boucher and Fragonard. The Met and the Rijksmuseum release these as CC0.
