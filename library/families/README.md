# Design families

Every movement is a whole kit: its own cutouts, button skin, layout grammar and motion. Each folder below holds that movement's kit. Tags are emotion words from the dartboard (no numbers).

## Organic & ornamental

- [Art Nouveau](ornament/art-nouveau/README.md): serenity, love, admiration
- [Art Deco](ornament/art-deco/README.md): admiration, anticipation, ecstasy
- [Psychedelia](ornament/psychedelia/README.md): amazement, ecstasy, distraction

## Order & reduction

- [Minimalism](order/minimalism/README.md): serenity, acceptance, pensiveness
- [Swiss / International](order/swiss/README.md): trust, interest, vigilance
- [Bauhaus](order/bauhaus/README.md): anticipation, trust, interest
- [Brutalism](order/brutalism/README.md): disapproval, vigilance, boredom

## Revolt & noise

- [Constructivism](revolt/constructivism/README.md): anticipation, aggressiveness, admiration
- [Dada](revolt/dada/README.md): amazement, distraction, contempt
- [Punk](revolt/punk/README.md): rage, contempt, aggressiveness

## Future & machine

- [Futurism](future/futurism/README.md): anticipation, ecstasy, aggressiveness
- [Cyberpunk](future/cyberpunk/README.md): apprehension, vigilance, awe
- [Vaporwave](future/vaporwave/README.md): pensiveness, boredom, distraction

## Excess & pop

- [Maximalism](excess/maximalism/README.md): ecstasy, overwhelm, amazement
- [Pop Art](excess/pop-art/README.md): joy, amazement, contempt

## Abstract

- [Abstract Expressionism](abstract/abstract-expressionism/README.md): rage, grief, overwhelm
- [Geometric Abstraction](abstract/geometric-abstraction/README.md): serenity, interest, trust
- [Op Art](abstract/op-art/README.md): distraction, amazement, apprehension
